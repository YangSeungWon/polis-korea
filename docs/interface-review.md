# 인터페이스 점검 — 2026-11-10

28개 대표 페이지 유형을 1200×900 / 390×844로 렌더링해 56개 화면을 캡처하고,
제목 스타일·조작 요소·카드·첫 화면 배치를 확인했다. 대표성은 tests/ui/pages.mjs를 따른다.
별도로 선거 메뉴는 320px와 다크 모드·키보드 포커스·터치 영역·목적지 링크를 검증했다.
56개 상태에서 문서 전체의 가로 넘침은 없었다. 이것은 사용성이 좋다는 뜻은 아니다.
표 내부 수평 스크롤, 선택된 회차의 화면 밖 배치, 중요 정보의 하단 밀림은 별개다.

## 판단

문제는 카드 수 자체보다 탐색·데이터·설명에 같은 시각적 무게를 주는 것이다.
기능 소개와 방법론이 실제 결과보다 먼저 크게 나오고, 같은 내용을 제목·설명·캡션으로 반복한다.
글자 크기를 일괄 축소하거나 모든 링크에 아이콘을 붙이는 것으로 해결하지 않는다.

## 적용할 공통 원칙

- 한 화면의 큰 제목은 하나. 섹션 제목은 작고 일정하게, 본문·메뉴는 기본 굵기를 쓴다.
- 중요도 차이가 없으면 크기·굵기·색을 새로 만들지 않는다. 여백과 정렬로 묶는다.
- 제목이 설명하는 내용을 부제·캡션·버튼에서 반복하지 않는다.
- 메뉴는 목적을 나타내는 짧은 이름으로 쓴다. 아이콘은 이름을 보조하며 글자를 대체하지 않는다.
- 비교할 독립 기록/조사에는 카드가 유효하다. 단순 이동 링크까지 모두 카드로 만들지 않는다.
- 결과와 선택이 먼저 보이고 방법 설명은 필요한 자리에서 읽게 한다.
- 선택 상태, 자료의 단위, 결손/무투표 구분, 조사 출처와 수치의 근거는 숨기거나 삭제하지 않는다.
- 모바일은 단순 축소가 아니다. 선택한 회차와 비교 결과가 첫 화면에서 보이는지 확인한다.

## 이번에 반영하는 범위

/elections.html의 기능 카드 여섯 개를 아이콘+짧은 이름으로 바꿨다.
최초 수정은 데스크톱 76px, 모바일 3×2 배열 156px이었다. 후속 사용자 피드백에 따라
글씨를 16px로 키우고 각 항목에 옅은 테두리를 넣었다. 현재 항목 높이는 96px, 모바일 전체는 200px이다. 굵은 메뉴 제목/설명/밑줄 CTA의
3단 반복을 없애고, 목록 제목은 '선거 기록' 16px/500으로 단순화했다.
기존 여섯 목적지와 크롤 경로는 유지한다.

역대 결과의 가로 회차 버튼은 연도·회차를 함께 표시하는 기본 선택 메뉴로 바꿨다.
모바일에서도 현재 선택이 가려지지 않으며, 과거 회차·별도 선거·데이터 미수집 표시는 보존한다.

나머지 표의 항목은 점검 결과와 후속 설계 방향이며, 아직 일괄 수정하지 않았다.
특히 방법 설명이나 데이터 표를 옮기는 변경은 해당 화면의 의미를 보존하며 별도로 검증한다.

## 문구와 구분 기호

가운데점 자체를 AI 작성 여부의 근거로 보지 않는다. 나열이 필요한 용어와 날짜·고유 명칭은 보존한다.
주정보와 보충정보는 `2025년 (21대)`처럼 괄호로, 조작 안내는 짧은 문장으로 표현한다.
이번에는 회차 선택, 선거일 설명, 지도 조작 안내와 선거 목록 소개를 정리했다.

## 후속 전체 점검과 반영

28개 대표 유형을 PC 1200px와 모바일 390px에서 다시 렌더링했다. 56개 화면에서
문서 전체 가로 넘침과 JavaScript 예외는 없었다. 320px 밝은/어두운 테마에서는
선거 메뉴의 터치 영역·키보드 포커스·목적지와 비교표의 가로 넘침도 확인했다.
스크린샷과 구조 측정을 병행했으며, 모든 개별 문서를 사람이 검수한 것은 아니다.

- 선거 메뉴: 짧은 이름은 유지하고 글자와 클릭 영역을 키웠다. 소개는 한 줄로 줄였다.
- 지지율: 산출 방식·기준일·출처를 각 수치에 붙였다. 긴 공통 문단은 두 문장으로 줄였고,
  모바일 섹션 제목과 조사 건수는 별도 줄로 배치했다. 평균과 단일 조사의 구분을 보존한다.
- 여론조사 허브: 같은 긴 제목을 두 번 표시하지 않는다. 선거일과 비교 대상을 선거명 아래에
  두고 일치 건수·비율을 옆에 배치해 320px에서도 함께 볼 수 있다. 9개 선거의 값은 유지했다.
- 선거 기록과 여론조사: 섹션 제목의 굵기와 크기를 낮춰 페이지 제목과 구분했다.
- 자료 안내: source, race, break, is_final 같은 구현 용어를 출처·지역별 결과·잠정 결과로 풀었다.

아직 남은 구조 문제는 홈의 긴 요약, 지역 찾기의 많은 선택지, 공통 메뉴와 목적지의 이름 불일치,
개별 선거의 중복 통계, 정당 계보의 작은 글자다. 인물·지역 표의 비교 구조와 정치 연표의 시간축은
유지하는 편이 낫다. 이번 검증의 무오류 결과가 이 사용성 문제들의 해결을 뜻하지는 않는다.
